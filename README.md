# مِرقاة للرصد الذكي

نظام رصد الدرجات **النهائية** لكل الفروع. لا يوجد رصد يومي أو شهري.

- **التقنيات:** Next.js 15 + Supabase + Vercel
- **الواجهة:** عربية بالكامل (RTL)، ومتجاوبة مع الجوال والتابلت والكمبيوتر

---

## التشغيل لأول مرة

### 1) Supabase

1. أنشئ مشروعاً جديداً من [supabase.com](https://supabase.com). يُفضّل اختيار أقرب منطقة للسعودية.
2. افتح **SQL Editor** وشغّل الملفات بالترتيب:
   1. `supabase/migrations/0001_schema.sql`: الجداول والصلاحيات ودوال الرصد الآمنة.
   2. `supabase/migrations/0002_seed.sql`: المراحل والصفوف والمواد وإعدادات البداية.
   3. `supabase/migrations/0003_section_pool.sql`: اختيار المعلمات لطلاب شعباتهن من طلاب الصف.
   4. `supabase/migrations/0004_academic_number.sql`: الرقم الأكاديمي معرّف الطالب، وحقول الاسم الإنجليزي والميلاد والجنسية ونوع الهوية.
   5. `supabase/migrations/0005_claim_same_section.sql`: تحسين رسالة الضم عندما تضيف معلمتان من نفس الشعبة نفس الطلاب.
3. من **Authentication → Sign In / Providers**:
   - أوقف **Allow new users to sign up**، لأن الحسابات تُنشأ من داخل النظام فقط.
   - أوقف **Confirm email**.
4. من **Project Settings → API** انسخ ثلاث قيم:
   - `Project URL`
   - `anon public`
   - `service_role`، وهذا المفتاح سرّي جداً.

### 2) Vercel

1. **Add New → Project**، ثم اختر المستودع `Smart-Monitoring`.
2. في **Environment Variables** أضف:

| المتغير | القيمة |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | anon public |
| `SUPABASE_SERVICE_ROLE_KEY` | service_role (لا تضعه في أي مكان آخر) |

3. اضغط **Deploy**.
4. من **Settings → Functions** اختر منطقة الخادم نفسها التي اخترتها لـ Supabase. هذا يسرّع الاستجابة.

### 3) أول حساب أدمن

من Codespaces أو أي جهاز فيه Node 20 أو أحدث:

```bash
npm install
NEXT_PUBLIC_SUPABASE_URL="https://xxxx.supabase.co" \
SUPABASE_SERVICE_ROLE_KEY="eyJ..." \
npm run create-admin -- admin "اسم المدير" "كلمة-مرور-قوية"
```

بعدها ادخل للموقع باسم المستخدم `admin`.

## ترتيب الإعداد داخل النظام (للأدمن)

1. **الإعدادات العامة:** اسم المدرسة، العام الدراسي، الترم الحالي، مدة التعديل (3 أيام افتراضياً).
2. **الفروع:** أضف الفروع، ثم حدّد **الصفوف** الموجودة في كل فرع.
3. **الصفوف والشعب:**
   - نوع الرصد لكل صف (درجات أو لفظي).
   - مستويات الرصد اللفظي.
   - شعب كل صف في كل فرع.
4. **المواد والتقييم:**
   - اربط المواد بالصفوف. مواد التمهيدي مربوطة تلقائياً.
   - حدّد لكل مادة أنواع التقييم والدرجة العظمى لكل نوع. الافتراضي: أعمال سنة 20، قصيرة 20، نهائي 60.
5. **الحسابات:** أنشئ المشرفات، ثم المعلمات. يمكن إضافتهن دفعة واحدة بلصق الأسماء، مع تحميل ملف إكسل ببيانات الدخول.
6. **الإسناد:** لكل معلمة صفوفها وشعبها وموادها. تبويب **مواد بلا معلمة** يكشف أي نقص.
7. **الطلاب → استيراد إكسل:** حمّل النموذج من نافذة الاستيراد، والصق البيانات، ثم ارفعه. الشعبة اختيارية.
   - الطلاب بدون شعبة تختارهم كل معلمة لشعبتها من شاشة الرصد («اختيار طلاب شعبتي»).
   - أو يوزّعهم الأدمن والمشرفة من صفحة الطلاب: فلتر «بدون شعبة»، ثم حدّد الطلاب، ثم «نقل لشعبة».
8. **افتح الرصد** من الإعدادات العامة.

### أعمدة ملف استيراد الطلاب

حمّل النموذج من نافذة الاستيراد. أعمدته بنفس ترتيب بيانات المدرسة:

| العمود | مطلوب | ملاحظة |
|---|---|---|
| الرقم الأكاديمي | يُنصح به | **المعرّف الأساسي:** يمنع تكرار الطالب عند إعادة الرفع |
| اسم الطالب الرباعي (عربي) | ✔ | |
| اسم الطالب (إنجليزي) | | |
| الصف الدراسي | ✔ | الأول الابتدائي / أول ابتدائي / 1 ابتدائي |
| تاريخ الميلاد | | هجري أو ميلادي |
| الجنسية، نوع الهوية | | |
| رقم الهوية | | يُسمح بتكراره (إخوة بهوية الأب) أو تركه فارغاً |
| الجنس، الشعبة، الفرع | | اختيارية. الفرع يمكن اختياره كفرع افتراضي عند الرفع |

**عند إعادة الرفع:** الطالب الموجود بنفس الرقم الأكاديمي تُحدّث بياناته، وتبقى شعبته كما هي إلا إذا حُددت شعبة في الملف.

النظام يعرض **معاينة** قبل الحفظ: الصفوف الصالحة، والأخطاء، والشعب غير الموجودة. ويمكن للأدمن إنشاء الشعب الناقصة تلقائياً.

## الأمان

- **صلاحيات قاعدة البيانات (RLS):** مفعّلة على كل الجداول.
  - المعلمة لا تقرأ إلا طلاب شعبها.
  - لا تكتب أي درجة إلا عبر الدالة `save_sheet`.
- **التحقق داخل قاعدة البيانات** في `save_sheet`، وليس في الواجهة فقط:
  - الإسناد
  - فتح الرصد
  - الترم الحالي
  - اكتمال كل الطلاب
  - عدم تجاوز العظمى
  - مدة التعديل
- **حماية الدخول:** إيقاف مؤقت بعد 5 محاولات فاشلة خلال 15 دقيقة. الحساب الموقوف ممنوع من نظام المصادقة نفسه.
- **سجل التتبع** يسجّل:
  - الدخول والخروج والمحاولات الفاشلة
  - كل حفظ وتعديل للكشوف
  - العمليات المرفوضة
  - فتح صفحات غير مصرّح بها
  - أخطاء الواجهة تلقائياً
  - التصدير وإدارة الحسابات
- **ترويسات أمان HTTP:** HSTS، ومنع التضمين في iframe، وnosniff.
